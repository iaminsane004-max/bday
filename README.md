## 💻 Running Locally (`npm run dev`)

The project is fully set up with **Vite** for lightning-fast hot reloading!

1. Open a terminal in the `birthday-website` folder:
   ```bash
   cd "birthday-website"
   ```
2. Start the local development server:
   ```bash
   npm run dev
   ```
3. Your browser will automatically open at:
   👉 **`http://localhost:5173/`**

Any changes you make to the code or text will update instantly in real-time!

## ✏️ How You Can Edit "Everything Means Everything"

### 1. 🔤 Click ANY Text Directly On The Page To Type & Edit It
When **Edit Mode** is active (it opens in Edit Mode automatically):
- Every single text on the entire page is an inline editable field:
  - Header lines: `"Happy"`, `"Birthday"`, `"my love"`, subtitles, pill badges (`★ for you, only ★`, `apr · 30 · 2026`, `priority: you`).
  - Section badge tags (`· no. 1 — about you ·`, `strictly classified, eyes only 🔒`).
  - The Dossier nicknames, official titles (`cutest sleeper 💤`), favorite snack, snack thief status, and quotes.
  - The live days counter or anniversary date.
  - All polaroid captions & dates.
  - The secret birthday cake wish message & title.
  - Every sticky note on the corkboard.
  - The love letter paragraphs, highlighted words, bullet points, air mail stamp, and sign-off.
  - The footer text and mascot dialogue!
- **Auto-saved**: The moment you type, it instantly auto-saves into your browser's `localStorage`!

### 2. 📷 Click ANY Photo To Replace It
- Hover over **any photo** (the big couple portrait, mini photos, polaroids, or sticker tiles).
- You will see a `📷 Change Photo` hint.
- Click it, and you can:
  - **Upload any photo from your computer** (saved locally in high quality as Base64).
  - Or paste an image web URL!

### 3. ➕ Add & ❌ Delete Memories & Notes Dynamically
- **Scrapbook Polaroids**:
  - Click **`➕ Add Another Polaroid Memory`** to add as many polaroids as you want!
  - Each polaroid has an `✕` delete button in edit mode.
  - Change captions, dates, and photos on the fly.
- **Corkboard Sticky Notes**:
  - Click **`➕ Pin Another Sticky Note`** to pin new colored sticky notes.
  - Each note has an `✕` delete button in edit mode.

### 4. 🎨 Change Color Themes With 1 Click
In the top bar, pick from 6 pastel color themes:
- 🌸 **Strawberry Milk** (Soft pinks & rose)
- 🍑 **Peachy Sunset** (Warm peach & coral)
- 💜 **Lavender Dream** (Pastel purple & violet)
- 🍵 **Matcha Mint** (Soft mint green & teal)
- 🍯 **Honey Vanilla** (Warm buttercup yellow & golden amber)
- ☁️ **Pastel Sky** (Dreamy baby blue & cloud white)

### 5. ✨ Click Floating Stickers To Change Emojis
In Edit Mode, click on any background floating sticker (🎈, 🍰, ✨, 🎉, 🎀, 🌸, ⭐, 🎁) to change it to any emoji you want!

### 6. 👁️ Preview Mode & ✏️ Done
- Click **`👁️ Preview Mode`** in the top bar or **`[ DONE / EDIT ]`** in the bottom floating dock to toggle off all dashed outlines and tools so you can experience the website exactly as she will see it!
